# Invoice App

A small Flask invoice generator with a single administrator login, PDF downloads, optional SMTP email, and an optional eTIMS-compatible gateway.

## Deploy to Render

1. Push this folder to a GitHub repository.
2. In Render, create a new Blueprint and select that repository. Render reads `render.yaml`.
3. Set `ADMIN_USERNAME` and a long, unique `ADMIN_PASSWORD` when prompted. Keep both out of Git.
4. Deploy, then use the generated `onrender.com` URL.

The blueprint uses a Starter web service and a 1 GB persistent disk for the SQLite database. This requires a paid Render plan and incurs Render charges. The `/healthz` route is public for service health checks; invoice and account routes require authentication. Do not remove the persistent disk or `INVOICE_DB` setting unless you have migrated the database.

`SECRET_KEY` is generated by Render. `COOKIE_SECURE` is enabled for HTTPS. Configure optional SMTP values (`SMTP_HOST`, `SMTP_FROM`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`) and eTIMS values (`ETIMS_URL`, `ETIMS_TOKEN`, `SELLER_TAX_ID`) as service environment variables only. Never commit secrets, customer invoices, or the SQLite database.

This app has one shared administrator account, not per-user accounts or role separation. Review operational, privacy, and tax-compliance requirements before using it with real customer data. The eTIMS endpoint must be an authorized gateway whose requirements you have independently verified.

## Local run

Create a virtual environment, install `requirements.txt`, set `SECRET_KEY`, `ADMIN_USERNAME`, and `ADMIN_PASSWORD`, then run `python InvoiceApp.py`. For example, in PowerShell:

```powershell
$env:SECRET_KEY = [guid]::NewGuid().ToString('N')
$env:ADMIN_USERNAME = 'admin'
$env:ADMIN_PASSWORD = 'replace-with-a-long-unique-password'
python InvoiceApp.py
```
